API Reference

All endpoints return standard JSON. Simply make a standard GET request to any of the routes below.

GET /kandas.json
List all 7 Kandas with counts & summaries

Returns the complete list of all 7 books with Sanskrit names, chapter totals, and verse counts.

GET /kanda/{kanda_id}.json
Details for a single Kanda (1 to 7)

Fetch metadata, description, and totals for a specified Kanda.

GET /kanda/{kanda_id}/sargas.json
List of all Sargas (chapters) in a Kanda

Returns an array of chapters in the selected book, along with individual verse counts for each.

GET /kanda/{kanda_id}/sarga/{sarga_id}.json
Full chapter with all its verses

Fetches all verses belonging to a specific chapter, complete with Sanskrit shloka and translations.

GET /slok/{kanda_id}/{sarga_id}/{verse_id}.json
Single verse detail

Returns an individual verse object including Devanagari text, IAST transliteration, and multilingual translations.

Code Examples

Copy-paste ready snippets to consume the API in your favorite environment.

JavaScript (Browser / Node.js) 
const url = 'https://bitwisebro.github.io/ramayana-api/slok/1/1/1.json';

fetch(url)
  .then(res => res.json())
  .then(data => {
    console.log(data.sloka);
    console.log(data.translations.english);
  })
  .catch(console.error);
Python 
import requests

url = "https://bitwisebro.github.io/ramayana-api/slok/1/1/1.json"
response = requests.get(url)
data = response.json()

print(data["sloka"])
print(data["translations"]["english"])
cURL 
curl -s https://bitwisebro.github.io/ramayana-api/slok/1/1/1.json | jq .
Dart / Flutter 
import 'dart:convert';
import 'package:http/http.dart' as http;

final uri = Uri.parse('https://bitwisebro.github.io/ramayana-api/slok/1/1/1.json');
final res = await http.get(uri);
final data = jsonDecode(res.body);
print(data['sloka']);
